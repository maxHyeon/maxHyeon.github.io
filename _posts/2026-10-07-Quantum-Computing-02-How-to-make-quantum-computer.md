# 컴퓨터는 무엇인가 ? 
- 컴퓨터를 만들기 위해서 우리는 컴퓨터가 무엇인지 정확히 알 필요가 있다. 위키 피디아의 정의에 따르면 컴퓨터는 '일련의 산술 또는 논리 연산을 자동으로 수행하도록 프로그래밍 할 수 있는 기계' 이다. 컴퓨터는 입력을 받아 일련의 프로그래밍 된 연산을 수행하고 결과를 반환한다. 그렇다면 양자 컴퓨터는 무슨 일을 하는것일까 ? 

# 양자 컴퓨터와 고전적 컴퓨터 
- 양자 컴퓨터가 아닌 고전적 ( classical ) 컴퓨터는 전압의 높낮이를 이용한 Bit 를 기본 단위로 이용하고, 양자 컴퓨터는 양자 역학의 원리를 따르는 큐비트 ( Qbit ) 를 기본 단위로 이용한다. 고전적 컴퓨터는 입력 Bit 를 일련의 프로그래밍 된 And, Or, Xor, Not 등의 논리 Gate 를 통과시켜 결과값을 출력 Bit 로 제공하고, 양자 컴퓨터는 입력 Qbit 를  Z, Y, X, Hadamard, Cnot 등의 선형대수 연산자 Gate 로 구성된 회로를 통과시켜 출력 Qbit 를 반환한다. 결국 고전 컴퓨터는 이산 수학과 전자기학을 이용해 연산을 수행하는 것이고, 양자 컴퓨터는 양자 역학과 선형 대수 기반의 논리 체계를 이용해 연산을 수행한다고 볼 수 있다. 새로운 단어들이 많이 보이지만, 블로그 시리즈를 따라가다 보면 이해할 수 있을 것이다. 지금은 일단 Bit(전자기학) - Qbit(양자 역학), 논리 Gate (이산 수학) - 양자 Gate (선형 대수) 의 차이점만 기억하면 된다.
